# Hyderabad Property Intelligence Dashboard 🏙️

## Project Overview

An interactive Power BI dashboard designed to analyze the Hyderabad real estate market. The dashboard provides insights into property listings, rental prices, property sizes, affordability, and furnishing trends across different zones of Hyderabad.

## Key Performance Indicators (KPIs)

- **Total Listings:** 486
- **Average Rent:** ₹24.46K
- **Average Cost per Sq. Ft.:** ₹16.81K
- **Average Property Size:** 1.23K Sq. Ft.
- **Average Total Monthly:** ₹41.27K

## Key Features & Analysis

### 1. Zone-wise Property Analysis
Comparison of property listings and prices across different Hyderabad zones.

### 2. BHK Category Analysis
Analysis of property prices across different BHK categories, including 1 RK, 2 BHK, 3 BHK, 4 BHK and 5+ BHK.

### 3. Property Affordability Analysis
Distribution of properties across different affordability bands.

### 4. Property Type Analysis
Comparison of rental prices across different property types.

### 5. Furnishing Status Analysis
Analysis of fully furnished, semi-furnished, and unfurnished properties across locations.

### 6. Property Size and Price Analysis
Exploration of the relationship between property size and price across different zones.

## Geographical Coverage

The dashboard covers four major Hyderabad zones:

- Central Hyderabad / Old City
- East Hyderabad / LB Nagar Zone
- North & Northwest Hyderabad
- West Hyderabad / IT Corridor

## Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Data Analysis
- Interactive Dashboard Design

## Project Objective

To transform property listing information into meaningful visual insights that help understand rental trends, property prices, affordability, and real estate patterns across Hyderabad.

## Key Learning Outcomes

- Designing interactive Power BI dashboards.
- Comparing real estate metrics across geographical zones.
- Presenting property market information through visualizations.
